no network requests for media, so these files must be redistributable.

## Painted plates — `../art/`

`kingdom.jpg`, `world-map.jpg`, `battle.jpg`, `menu.jpg`, `port.jpg`,
`siege.jpg`, `champion-company.jpg`, `champion-north.jpg`,
`champion-river.jpg` and `app-icon.png` were generated for this project and are
used as titles, map and tab art, champion portraits and the launcher icon.

`tools/make-icons.py` cuts every Android mipmap from `art/app-icon.png`.
